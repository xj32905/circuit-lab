# 观电 · Circuit Notebook

一个面向模电学习的网页实验台，把教材原图、动态电路和双通道波形放在一起。

## 当前可用

- 基于本地 CircuitJS1 的真实电路计算与约定电流方向动画。
- 共射极、RC 低通、半波整流滤波、运放反相放大器四个示例。
- 暂停、重置、仿真速度、元件参数修改和原生完整电路编辑。
- 双通道节点电压 / 支路电流波形、去直流显示、时间窗、鼠标读数、峰峰值和幅度比。相同单位使用共同纵轴；不同单位使用独立纵轴。
- 上传、拖入或粘贴截图，原图放大对照。
- 截图识别接口：上传图像 → 视觉模型 → CircuitJS 数据验证 → 显示摘要与假设 → 载入并仿真。
- 电路与原图保存为 JSON、重新导入、CircuitJS 文本/XML 导入、波形导出 CSV。
- 手机和桌面布局。

## 自动识别需要什么

在页面的“识别设置”里提供支持图像输入的 API 地址、模型 ID 和 Key。支持 Chat Completions 兼容协议及 OpenAI Responses 协议。

没有预置或共享模型密钥。未配置 API 时，示例、仿真、原图对照和电路导入仍能使用。密钥只保留在当前页面内存中；不写入本地存储、导出文件或服务器日志。刷新页面后需要重填。模型名称与地址保存在浏览器本地。识别请求由应用服务器转发至用户配置的公共 HTTPS 接口，图像会随请求发送给该服务商。

实际识别准确率尚未验证：本次未取得真实视觉 API 凭据。自动化浏览器测试使用了明确的测试替身验证识别流程，不能据此声称真实教材图片已能准确重建。必须核对元件数值、交叉点和晶体管引脚。没有明确数值时模型必须说明假设，无法支持的图返回原因，不替换为模板。

第一版识图重点覆盖电阻、电容、电感、硅二极管、齐纳二极管、NPN/PNP、理想运放、信号源和开关。复杂 IC、精确器件模型与 MOS 管自动识别尚未作为可靠功能交付；可在完整引擎中手动搭建或导入已有电路。

## 运行

Node.js 22 或更新，无需安装 npm 运行依赖。

```bash
npm start
```

也可以用全局命令启动并自动打开浏览器（通过 `bin/circuit-lab.mjs` 软链到 `~/.local/bin/circuit-lab`）：

```bash
circuit-lab            # 启动并打开浏览器
circuit-lab --no-open  # 只启动，不打开浏览器
circuit-lab --port=5000
```

`server.mjs` 同样支持 `--open`、`--no-open`、`--port=<n>`。

服务监听 `0.0.0.0`，默认端口 4175，也支持环境变量 `PORT`。健康检查为 `/api/health`。网页需通过此服务器打开，双击 HTML 不能运行服务器端截图识别。

保存的成员网站使用相同命令 `node server.mjs`，无安装步骤。引擎和示例保存在 `public/engine`，普通仿真不需要访问第三方仿真网站。字体现已随应用保存；中文使用系统字体。

## 文件

- `public/app.js`：交互、引擎桥接、上传与设置。
- `public/scope.js`：基于真实仿真时间步采样的环形缓冲和示波器。
- `public/native-format.js`：保留原生 XML/模型的读写与参数修改。
- `public/circuit-format.js`：识别结果、单位及 CircuitJS 文本验证。
- `public/presets.js`：示例电路及学习笔记。
- `server.mjs`：静态资源、识图代理、目标地址验证和超时。
- `vision-prompt.mjs`：电路格式、引脚定义、拓扑与假设约束。
- `scripts/vendor-engine.py`：下载上游引擎构建、资源和许可证。
- `test/`：必要的解析、HTTP、数值及浏览器流程检查。

## 验证

`npm test` 运行 9 项解析与服务测试。完整浏览器测试需要 Playwright 与 Chromium；可用 `PLAYWRIGHT_MODULE` 和 `CHROMIUM_PATH` 指定安装位置，执行 `node test/browser.mjs`。

2026-09-19 验证结果：

| 检查 | 实测 |
| --- | --- |
| 共射极反相 | 输出与输入反相，幅度比约 3.653 |
| RC：1kΩ、1µF、100Hz | 幅度比 0.846724，理论值 0.846733 |
| RC 电阻改为 2kΩ | 幅度比约 0.622665 |
| 运放 Rin=1kΩ、Rf=3kΩ | 反相，幅度比约 2.99988 |
| 运放输入增至 6V | 输出约 ±15V 限幅 |
| 半波整流滤波稳态 | 输出约 6.21–7.41V |
| 编辑/保存/重新导入 | 通过，保留原生 XML |
| 识别流程 | 测试替身验证通过，未验证真实识图 |
| 手机 390px | 无横向溢出，切换、暂停和设置可用 |

共射极示例为便于观察，从近似静态电容电压开始；该假设同时显示在界面中。整流滤波从电容零电压启动。流动光点仅表示约定电流方向与相对强弱，不表示电子实际运动速度。
